# 🐕 汪汪时间管理局

> 一只卡通小狗 × 未来时间管理局的每日个人工作台
> Daily Doggy Dispatch · 一份每天更新的狗狗日程报

一个零依赖、开箱即用的手机端个人工作台。把「每日计划、习惯打卡、阅读、运动、记账、灵感」整合在一份会呼吸的日程报里，蓝色科技感底纹 + 手绘小狗 + 时间旅行元素，活泼有趣，同时保持信息清晰、适合长期使用。

---

## ✨ 主题风格

- **视觉**：蓝色科技感底纹（浅蓝渐变 + 细密科技网格 + 顶部光晕），搭配 5 色轮转的活力模块色（翠绿 / 亮蓝 / 琥珀 / 珊瑚红 / 紫罗兰）
- **故事感**：首页头图是一只戴耳机的卡通小狗坐在星环时间机器里，周围漂浮着时钟与数字
- **文案**：品牌名「汪汪时间管理局」，每日一句按星期轮换（"时间像骨头，啃一口少一口…"、"摇着尾巴也要继续"），模块命名贴合时间旅行设定（灵感时光机、能量账本、时光收藏夹）

---

## 📱 功能模块

| 模块 | 类型 | 说明 |
| --- | --- | --- |
| 首页 | dashboard | 问候 + 今日概览环形 + 置顶任务 + 快速记录 + 本周趋势 |
| 今日任务 | todo | 紧急 / 重要 / 随手 三级优先级，勾选完成 |
| 每日签到 | checkin | 喝水、早睡等每日打卡，自动统计连续天数，带月历视图 |
| 阅读进度 | progress | 书籍进度条（当前 / 目标 / 单位） |
| 运动打卡 | progress | 跑步、力量训练等分钟数进度 |
| 能量账本 | finance | 收入 / 支出 + 分类 + 月度占比环形图 |
| 灵感时光机 | note | 文字、摘录、心情标签 |
| 时光收藏夹 | note | 热点内容收藏、稍后读 |
| 洞察 | insight | 各模块完成度柱状图 + 支出构成环形图 |

每个模块都遵循「记录 → 执行 → 统计 → 反馈」的闭环。

## 🚀 快速开始

直接用浏览器打开 `workbench-mobile.html` 即可，无需安装、无需后端、无需构建。

```
workbench-mobile/
├── workbench-mobile.html      # 主应用（单文件，含全部样式与逻辑）
└── workbench-assets/
    ├── greet-banner.jpg       # 首页 hero 插画（卡通小狗 × 时间机器）
    └── avatar.jpg             # 抽屉默认头像
```

> 建议在手机浏览器中打开以获得最佳体验；桌面浏览器也可正常使用（最大宽度 480px 居中布局）。

---

## 🛠 技术实现

- **纯前端单文件**：HTML + CSS + 原生 JavaScript，无任何运行时依赖
- **数据存储**：浏览器 `localStorage`，数据仅保存在当前设备的当前浏览器中
- **样式架构**：所有颜色、圆角、阴影、背景图均通过 CSS 变量（`:root` token）统一管理，改一处即可整站换肤
- **图标**：内联 SVG 线性图标（Lucide 规范），不依赖图标字体或网络
- **响应式**：底部 Tab 栏、抽屉导航、底部弹窗，适配手机安全区

---

## ⚠️ 数据说明（重要）

- 你填写的所有内容**只保存在这台设备的这个浏览器里**。
- 换台电脑、换个浏览器、或者清空浏览记录，之前的数据就没了。
- 手机端和电脑端数据**不会互相同步**，各记各的。
- 如果需要多设备同步或多人共享，这个版本做不到，需要额外搭建后端。

## 🎨 自定义指南

所有可定制内容集中在 `workbench-mobile.html` 的 `<script>` 顶部的 `CONFIG` 对象中：

| 配置项 | 说明 |
| --- | --- |
| `owner` / `slogan` / `brand` | 抽屉品牌名、副标题、品牌字符 |
| `quotes` | 一周七天的每日一句 |
| `modules` | 模块列表，每个模块含 `key` / `name` / `icon` / `type` / `desc` / `seed` |
| `quickAdd` | 首页快速记录按钮 |
| `overview` | 首页概览环形的计算规则 |

修改 `:root` 中的 CSS 变量即可一键换肤，无需改动组件样式。
